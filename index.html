아이폰 단독 v3 설치 방법

  1. 아이폰에 Scriptable 앱이 설치되어 있는지 확인합니다. 설치되어 있지 않다면 App Store에서 무료로 설치합니다.
  2. 위 아이폰 단독 v3 다운로드를 누른 뒤 파일 앱에서 H2S 스레드 아이폰 단독 v3.shortcut을 열어 단축어를 추가합니다.
  3. Threads 게시물에서 공유 → 단축어 → H2S 스레드 아이폰 단독 v3을 선택합니다.
  4. 처음 실행 시 Scriptable 실행·Threads 접근·사진 저장을 묻는 창이 뜨면 확인 후 허용합니다.
