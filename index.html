아이폰 설치 방법

  1. Safari에서 위 v2.1 단축어 다운로드를 누릅니다.
  2. 파일 앱의 다운로드 폴더에서 H2S 스레드 다운로드 v2.1.shortcut 파일을 열어 단축어를 추가합니다.
  3. Threads 게시물에서 공유 → 단축어 → H2S 스레드 다운로드 v2.1을 선택합니다.
  4. 처음 실행할 때 웹사이트·사진 앱 접근을 요청하면 확인 후 허용합니다.
